# FUTURE_DS_03
## Marketing Funnel & Conversion Performance Analysis

### 📌 Project Overview
This project focuses on analyzing marketing funnel performance using Microsoft Power BI to understand visitor engagement, lead generation, customer conversion, campaign costs, and revenue.

### 🎯 Objective
To evaluate marketing channel and campaign performance, identify conversion trends, and understand which channels contribute most to customer acquisition and revenue.

### 🛠️ Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Marketing Funnel Dataset (CSV)

### 📊 Key Analysis
- Marketing Funnel Analysis
- Customers by Marketing Channel
- Revenue by Marketing Channel
- Monthly Revenue Trend
- Campaign Cost vs Revenue
- Visitor-to-Lead Conversion Rate by Channel
- Lead-to-Customer Conversion Rate by Channel
- Revenue by Campaign
- KPI Monitoring: Total Visitors, Total Leads, Total Customers, and Overall Conversion Rate

### 📁 Files Included
- Power BI Dashboard (`.pbix`)
- Dashboard Screenshot
- Marketing Funnel Dataset (`.csv`)- Stimulated Dataset

### 💡 Project Outcome
The dashboard provides an overview of marketing funnel performance, conversion rates, campaign spending, and revenue to support data-driven marketing decisions.
